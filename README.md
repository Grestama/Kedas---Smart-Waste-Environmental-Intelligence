# WasteLink Bali — Platform Pengelolaan Sampah Komunitas & Ekonomi Sirkular

WasteLink Bali adalah platform pengelolaan sampah terintegrasi berbasis komunitas adat/banjar dan ekonomi sirkular di Bali. Platform ini mendigitalisasi rantai nilai sampah dari pemilahan di rumah warga, penjemputan oleh petugas banjar, inspeksi kualitas dan penimbangan tervalidasi, insentif WastePoints, hingga agregasi material batching ke mitra daur ulang berizin.
